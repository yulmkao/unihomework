# Homework 6

Техническое задание
Разработка модуля валидации пользовательских данных

Проект: UserValidator
Версия: 1.0
Дата: 21.10.2025

1. ОПИСАНИЕ ПРОЕКТА
Разработать класс для валидации персональных данных пользователя.
Модуль должен проверять корректность вводимых данных согласно
бизнес-требованиям.

2. ТРЕБОВАНИЯ К ВАЛИДАЦИИ

2.1. Валидация имени пользователя
- Параметр: Имя (name)
- Формат: Только русские буквы
- Правила:
  - Первая буква - заглавная
  - Остальные буквы - строчные
  - Длина: от 2 до 15 символов включительно
- Примеры валидных значений:
  - "Анна"
  - "Владимир"
  - "Ян"
- Примеры невалидных значений:
  - "анна" (строчная первая буква)
  - "А" (слишком короткое)
