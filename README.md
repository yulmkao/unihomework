# Classwork 5

## TextEditor

Создайте консольное приложение TextEditor:

1. Считывает строку с клавиатуры
2. Показывает меню:

Выберите действие:
1) Найти подстроку
2) Заменить подстроку
3) Разбить строку на слова
4) Объединить слова в строку
0) Выход

3. Реализовать методы:
- findSubstring(?) – поиск подстроки
- replaceSubstring(?) – замена подстроки
- splitWords(?) – разбиение строки на слова
- joinWords(?) – объединение массива слов в строку

Использовать только String (charAt(), length(), equals(), + для конкатенации)

Пример работы:

Введите текст:

Java is cool language

> 1

Введите подстроку:

cool

Найдено в позиции: 8

> 2

Введите подстроку для замены:

cool

Введите новую подстроку:

powerful

Результат: Java is powerful language

> 3

Слова:

Java

is

cool

language

> 4

Введите слова через запятую:

Java,is,cool

Результат: Java is cool
