# Classwork 9

## Класс Student

Создать класс Student со следующими полями:
- firstName (String) - имя студента
- lastName (String) - фамилия студента
- age (int) - возраст
- group (String) - номер группы
- averageGrade (double) - средний балл
- isActive (boolean) - активно ли обучение

Конструкторы:
- Конструктор по умолчанию
- Конструктор, принимающий имя, фамилию и группу
- Конструктор, принимающий все поля

Методы:
- displayInfo() - выводит информацию о студенте
- updateGrade(double newGrade) - обновляет средний балл
- activateStudent() - активирует студента
- deactivateStudent() - деактивирует студента
- transferToNewGroup(String group) – меняет group и выводит сообщение о переводе
